## 1. Product Objectives
1. Showcase flagship projects in Cybersecurity, Autonomous Multi-Agent AI, and Cloud Architecture with interactive live demos and GitHub links.
2. Deliver flawless Core Web Vitals: Largest Contentful Paint (LCP) < 1.2s, Cumulative Layout Shift (CLS) = 0, First Input Delay (FID) < 50ms.
3. Fully responsive across mobile (375px+), tablet, and 4K desktop screens.
4. Pass automated Playwright E2E verification on every commit.
