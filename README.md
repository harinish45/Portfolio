## 🚀 Key Features

* **Interactive Three.js Canvas:** Real-time dynamic particles and interactive background geometry.
* **Bento Grid Showcase:** Highlights flagship projects in Cybersecurity, Autonomous Multi-Agent Systems, and Cloud Architectures.
* **Journey Timeline:** Visual progression of engineering experience, education, and technical certifications.
* **Serverless Contact Form:** Secure serverless handler via Vercel Edge Functions (`/api/contact`).
* **Automated E2E Verification:** Rigorous visual and interaction testing with Playwright suite (`tests/portfolio.spec.ts`).

## 📦 Quick Start

### Local Testing
```bash
git clone https://github.com/harinish45/Portfolio.git
cd Portfolio
npm install

# Run automated Playwright tests
npm test

# Run local web server
npx serve .
```
